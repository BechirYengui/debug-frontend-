# Défi 02 : Ouverture de vanne

**Difficulté :** ★☆☆ · **Famille :** le clic n'arrive jamais au bouton.

## Cause

Le bouton porte l'attribut `disabled` directement dans le HTML :

```html
<button class="btn btn-primary" id="open-valve" disabled aria-disabled="true">Valider la commande</button>
```

Le code de la page calcule bien l'état « prêt » (les 5 verrouillages passent) mais, dans
`applyReadiness()`, il ne fait que :

```js
el.open.setAttribute('aria-disabled', ready ? 'false' : 'true');
el.open.classList.toggle('is-ready', ready);
```

Il met à jour l'attribut ARIA et une classe CSS, **jamais la propriété `disabled`**.
Et `public/c/02.css` contient :

```css
.btn.is-ready{ opacity: 1; cursor: pointer; box-shadow: ...; }
```

qui annule le style `.btn[disabled]{opacity:.45;cursor:not-allowed}` de la feuille commune.
Résultat : le bouton **a l'air actif** (opaque, curseur pointeur, halo) alors qu'il est inerte.
Un élément `disabled` ne reçoit aucun événement de souris : pas de `click`, pas de `mousedown`.

## Diagnostic pas à pas

1. **Console** : vide. **Network** : rien au clic.
2. **Elements** : sélectionne le `<button>` et lis la ligne d'ouverture **en entier**.
   `disabled` y est, après les classes. C'est le piège : on lit `class="btn btn-primary is-ready"`
   et on saute l'attribut suivant.
3. Vérification Console :
   ```js
   const b = document.getElementById('open-valve');
   b.disabled            // true
   b.matches(':disabled') // true
   ```
4. Elements → **Event Listeners** : le listener `click` est bien présent. Le handler existe,
   il n'est jamais déclenché.
5. L'écart entre `aria-disabled="false"` et `disabled` présent est la signature du bug :
   quelqu'un a mis à jour l'accessibilité et le style, pas l'état réel.

## Contournements

**A. Retirer l'attribut (Elements)**
Double-clic sur `disabled` dans la balise → efface → `Entree`. Puis clique.
(Ou clic droit sur le nœud → *Edit attribute*.)

**B. Console**
```js
document.getElementById('open-valve').disabled = false;
document.getElementById('open-valve').click();
```

**C. Rejouer la requête**
```js
await fetch('/api/challenge/02/solve', {
```

## Le réflexe à garder

`disabled` est un **état DOM**, pas un style. Une page peut parfaitement afficher un bouton
« actif » et le laisser inerte. Sur un bouton mort, regarde toujours les attributs bruts
(`disabled`, `readonly`, `inert`, `aria-disabled`) avant le CSS, et compare `:disabled` à
l'apparence.
