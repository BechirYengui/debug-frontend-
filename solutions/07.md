# Défi 07 : Expédition d'une commande

**Difficulté :** ★★★ · **Famille :** le clic arrive, le code déraille.
Le code est dans `public/c/07.js`, minifié sur une ligne.

## Cause

Le bouton n'a **aucun** listener à lui. Toute l'interactivité de la carte passe par une
délégation posée sur `document` :

```js
document.addEventListener("click", function (e) {
  var t = e.target.closest ? e.target.closest("[data-cmd]") : null;
  if (!t) { cls(); return; }
  var c = t.getAttribute("data-cmd");
  if (c === "dispatch") { tx(); return; }   // <- l'envoi
  if (c === "pick")     { S.ref = t.getAttribute("data-ref"); upd(); return; }
  if (c === "tip")      { pop(t); return; }
});
```

Mais la carte elle-même, `#order-panel`, qui est un **ancêtre** du bouton, coupe la remontée :

```js
E.panel.addEventListener("click", function (e) {
  e.stopPropagation();                                   // <- ici
  if (!e.target.closest("[data-cmd=tip]")) { cls(); }
});
```

Ce listener existe pour une raison plausible : fermer les popovers quand on clique ailleurs,
sans que le clic « intérieur » ne déclenche la fermeture globale. Mais `stopPropagation()`
arrête la propagation **pour tous les écouteurs situés plus haut**, y compris la délégation sur
`document`. L'événement `click` naît sur le bouton, bulle jusqu'à `#order-panel`, et meurt là.

Symptôme révélateur : **rien** de ce qui est délégué ne marche à l'intérieur de la carte :
ni le bouton, ni la sélection de ligne (`data-cmd="pick"`), ni l'info-bulle (`data-cmd="tip"`).
En revanche les `<select>` et l'`<input>`, abonnés directement, répondent parfaitement.

## Diagnostic pas à pas

1. **Console** vide, **Network** vide. Le bouton est bien la cible du clic
   (`Inspecter` → `button#dispatch-order`), il n'est pas `disabled`, `pointer-events` vaut `auto`.
2. **Elements** → bouton sélectionné → **Event Listeners** :
   - décoche *Ancestors* : la liste est vide, aucun listener propre.
   - recoche *Ancestors* : deux `click` apparaissent, l'un sur `div#order-panel`, l'autre sur
     `document`. Le handler utile est tout en haut, et il y a quelque chose entre les deux.
3. En Console (Chrome) :
   ```js
   getEventListeners(document).click.length            // 1
   getEventListeners(document.getElementById('order-panel')).click  // 1 listener
   ```
4. Confirme la coupure sans lire le code :
   ```js
   document.addEventListener('click', e => console.log('atteint document ?'), true);  // capture : passe
   document.addEventListener('click', e => console.log('remonte jusqu au document'));  // bulle : silencieux
   ```
   La phase de capture arrive, la phase de bulle non → quelqu'un appelle `stopPropagation`
   entre les deux.
5. **Sources** → ouvre `07.js` → bouton **`{}`** (Pretty print) en bas du panneau.
   Cherche `stopPropagation`. Tu tombes sur le listener de `#order-panel`.
   Variante sans lecture : Sources → **Event Listener Breakpoints** → *Mouse* → `click`,
   puis clique et avance en `F9` : tu vois le handler du panel s'exécuter, et jamais celui
   du document.

## Contournements

**A. Neutraliser `stopPropagation` (Console)**
Le plus rapide, et sans toucher au DOM :
```js
Event.prototype.stopPropagation = function () {};
document.getElementById('dispatch-order').click();
```

**B. Retirer le listener fautif (Console, Chrome)**
`getEventListeners` donne la référence exacte de la fonction anonyme :
```js
const panel = document.getElementById('order-panel');
const l = getEventListeners(panel).click[0];
panel.removeEventListener('click', l.listener, l.useCapture);
document.getElementById('dispatch-order').click();
```

**C. Sortir le bouton du sous-arbre (Elements)**
La délégation est sur `document` : hors de `#order-panel`, le clic remonte sans obstacle.
```js
document.body.appendChild(document.getElementById('dispatch-order'));
document.getElementById('dispatch-order').click();
```
(En Elements, un simple glisser-déposer du nœud hors de la carte fait la même chose.)

**D. Rejouer la requête**
```js
await fetch('/api/challenge/07/solve', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ challengeId: '07', action: 'validate' })
}).then(r => r.json());
```
Attention : `dispatchEvent(new MouseEvent('click', {bubbles:true}))` sur le bouton **ne marche pas** :
l'événement synthétique bulle par le même chemin et se fait couper au même endroit.

## Le réflexe à garder

Coche **Ancestors** dans Event Listeners : c'est là que se cache la délégation. Quand le
handler utile est sur `document` ou `body`, tout ancêtre intermédiaire peut le tuer avec
`stopPropagation()` : souvent posé pour gérer un popover ou un menu.
Le test capture-vs-bulle (`addEventListener(..., true)`) localise la coupure en deux lignes,
sans lire une seule ligne du bundle.
